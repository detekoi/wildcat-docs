# Wildcat Documentation Site

This repository contains the documentation site for the Wildcat platform. Eleventy builds the documentation pages, and Firebase Hosting serves the static files.

## Project Structure

```
wildcat-docs/
├── public/           # Output directory generated by Eleventy for Firebase Hosting
├── src/             # Source files for pages, styles, scripts, and translations
├── .eleventy.js     # Eleventy build configuration
├── firebase.json    # Firebase Hosting configuration
└── package.json     # Node.js dependencies and build scripts
```

## Development

To start the Eleventy development server with live reload, run:

```bash
npm run dev
```

To build the static site into the `public/` directory, run:

```bash
npm run build
```

To preview the output with the Firebase Emulator, run:

```bash
firebase emulators:start --only hosting
```

## Deployment

To deploy the compiled site to Firebase Hosting, run:

```bash
firebase deploy --only hosting
```

## Adding a Custom Domain

1. Open the **Firebase Console** and select **Hosting**.
2. Select **Add custom domain**.
3. Enter your domain name (for example, `docs.yourdomain.com`).
4. Add the specified DNS records at your domain provider.

## Adding Documentation Pages

To add new documentation pages:

1. Create Nunjucks (`.njk`) or HTML templates in `src/`.
2. Add links to new pages in `src/index.njk` or navigation components.
3. Run `npm run build` to compile the site.
