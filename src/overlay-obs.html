Overview

The Wildcat Chat Overlay shows Twitch and YouTube Live chat messages in OBS Studio. You can change its settings in the Chat Scene Creator on the web, or in the config panel of the OBS browser source.

Get Started with the Chat Overlay

Platform Support

The overlay connects to Twitch and to YouTube. You select the platform in the config panel.

  • Twitch: Enter your channel name (for example, wildcatgamer). Badges and emotes load automatically.
  • YouTube: The overlay supports YouTube live chat for public and unlisted streams. For a public stream, enter your channel username, channel ID, video URL, or video ID. For an unlisted stream, enter the video URL. Private streams are not supported.

OBS Setup Instructions

Do these steps to add the chat overlay to OBS Studio:

  1. In OBS Studio, open the Sources panel. Click +. Then select Browser.
  2. Enter a name for the source (for example, "Twitch Chat").
  3. Paste the URL from the Chat Scene Creator into the URL field. If you cannot paste the URL, clear the "Local file" checkbox.
  4. Set Width to 320 and Height to 600.
  5. Click "OK" to add the browser source to your canvas.
  6. Change the Settings: Save your settings in the Chat Scene Creator. They sync live to OBS. As an alternative, right-click the Browser Source in OBS. Then select Interact to change the settings locally.
  7. In the interactive window, enter your channel information. Click the settings gear (). Then click "Connect".

Advanced OBS Tips

  • For live sync from the Chat Scene Creator, leave Shutdown source when not visible and Refresh browser when scene becomes active cleared.
  • To hide the scrollbars, add body { overflow: hidden; } to the Custom CSS field.
  • Settings save to the OBS cache. If you clear the OBS cache for this source, set your visual settings again.
