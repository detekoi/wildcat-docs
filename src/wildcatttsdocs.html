WildcatTTS Bot Documentation

WildcatTTS is currently invite-only. Request access.

Commands

All TTS commands start with !tts.
For example: !tts status
Select any command row below to show usage details.
Broadcasters and viewers can also change settings in the WildcatTTS Web Dashboard.
Viewers can set personal TTS preferences in the web dashboard with !myvoice in chat.

Permission: Moderator
Mod!tts mode [all|command|bits_points_only]
!tts mode all (Speaks all chat messages and events; default mode)
!tts mode command (Only speaks commands and enabled events)
!tts mode bits_points_only (Only speaks Bits cheers and Channel Point redemptions)
!tts mode bits (Alias for bits_points_only)
!tts mode points (Alias for bits_points_only)
!tts mode (Shows current mode)

Notes: all: TTS speaks all chat messages (except ignored users) and enabled events, based on !tts permission.
command: TTS speaks only commands (such as !tts <message>) and enabled events. TTS ignores regular chat.
bits_points_only: TTS speaks only Bits cheers and Channel Point redemptions. TTS ignores regular chat and commands.

Permission: Moderator
Mod!tts permission [everyone|all|subs|vip|mods]
!tts permission everyone
!tts permission subs
!tts permission vip
!tts permission mods
!tts permission (shows the current permission filter)

Notes: everyone or all: TTS speaks messages from all users (Default).
subs: TTS speaks messages from subscribers, VIPs, moderators, and the broadcaster.
vip: TTS speaks messages from VIPs, moderators, and the broadcaster.
mods: TTS speaks messages only from moderators and the broadcaster.
This setting does not affect command mode.

Permission: Moderator
Mod!tts bits [on|off|min <amount>]
Mod!tts bits on
Mod!tts bits off
Mod!tts bits min 100
Mod!tts bits (shows current Bits-for-TTS status)

Description:

  • on: Starts Bits-for-TTS mode. TTS reads only messages with enough Bits.
  • off: Stops Bits-for-TTS mode.
  • min <amount>: Sets the minimum Bits required (for example, min 100).

Permission: Moderator

Channel Points → TTS (Web Dashboard Only)
Channel Points → TTS

Note: This feature is configured exclusively through the WildcatTTS Web Dashboard under the "Channel Points → TTS" section.

How It Works:

  1. Streamer Setup: Turn on the feature in the dashboard.
  2. Reward Creation: The bot creates a custom Channel Point reward on your Twitch channel.
  3. Viewer Redemption: Viewers redeem the reward with a message that TTS speaks.
  4. Content Policy: Filter text with length limits, link blocking, and banned words.

Configuration Options:

  • Basic Settings: Reward title, cost in points, prompt text, and queue settings.
  • Advanced Settings: Global cooldown, stream limit, and user limit.
  • Content Policy: Minimum and maximum message length, link blocking, and banned words.

Skip the Reward Queue:

  • Default Setting: This option is on by default for immediate TTS playback.
  • When On: TTS plays redemptions immediately without adding them to your Twitch review queue.
  • When Off: Redemptions wait in your Twitch dashboard for manual approval before TTS plays.
  • Tip: Turn on for instant playback. Turn off for moderation review before audio plays.

TTS Modes: Works with all TTS modes (All Messages, Commands Only, Bits/Points Only).

Requirements: Grant channel:manage:redemptions and channel:read:redemptions permissions during dashboard login.

Permission: Streamer/Broadcaster (via Web Dashboard)

Emote Description Management (Moderator Only)

Mod!tts emote <emoteName>
Usage:
Mod!tts emote LUL (shows the current cached description)
Mod!tts emote regenerate LUL (clears cache; AI will re-describe on next use)
Mod!tts emote set LUL = a person laughing (sets a custom description — channel emotes only)

Description:

  • Show the current AI description for an emote.
  • Clear the cached description so AI creates a new description on next use.
  • Set a custom description for a channel emote.

Notes: When an emote appears in chat for the first time, AI generates a text description. The bot caches descriptions permanently. Use this command to view, change, or regenerate emote descriptions.

Permission: Moderator (set/regenerate only for channel emotes)

Pronunciation & Filtering (Moderator Only)

Mod!tts pronounce <word> = <how to say it>
Usage:
Mod!tts pronounce wcat = wildcat (adds or changes an entry)
Mod!tts pronounce list (shows the entries for this channel)
Mod!tts pronounce remove wcat (removes an entry)
Mod!tts pronounce off lfg (stops a built-in entry)
Mod!tts pronounce test ngl that was wild (shows the result without speaking)
Mod!tts pronounce defaults (lists the built-in entries)

Description:

  • Add a word and the text that TTS speaks in its place. Your entry replaces a built-in entry with the same word.
  • Remove your entry. If a built-in entry has the same word, that built-in entry becomes active again.
  • Stop a built-in entry. To start it again, use the remove sub-command.
  • Show what TTS will say for some text. The bot does not speak the text.
  • The broadcaster can use !tts pronounce clear to remove all entries for the channel. Built-in entries stay active.

Notes: The word is not case-sensitive, and it must match a full word. A channel can have a maximum of 100 entries. A word can have a maximum of 40 characters. A spoken form can have a maximum of 120 characters. You can also change these entries in the Web Dashboard.

Permission: Moderator (broadcaster only for clear)
Mod!tts profanity <on|off|status>
Usage:
Mod!tts profanity on
Mod!tts profanity off
Mod!tts profanity status (shows the state, the language, and the number of words)

Notes: The filter is off until you start it. It replaces rude words with milder words. It does not remove the message. The Banned Words list in the Web Dashboard removes a full message.

Permission: Moderator

The language_boost feature improves pronunciation for specific languages and dialects. This setting helps in multilingual chats and non-English streams.

Set a personal language preference with !tts language <language_name>. Moderators can set a channel default with !tts defaultlanguage <language_name>.

Emote Descriptions

WildcatTTS uses Google Gemini AI to describe Twitch emotes in chat messages. Instead of reading the emote code (for example, "LUL"), TTS speaks a description such as "a person laughing." The bot caches descriptions permanently to prevent repeated AI requests.

How It Works

  1. When an emote appears for the first time, AI analyzes the emote image and creates a short description.
  2. The bot caches the description permanently after first generation.
  3. Later uses of the emote use the cached description instantly without new AI processing.

Managing Descriptions

Moderators can use !tts emote to view, regenerate, or set emote descriptions. See the Emote Description Management table for details.

Pronunciation Dictionary

Chat uses many short forms that TTS speaks one letter at a time. The pronunciation dictionary changes them into full words. For example, TTS speaks ngl as "not gonna lie" and glhf as "good luck have fun". WildcatTTS includes a built-in list of about 70 common short forms. You can also add your own entries.

How It Works

  • The word is not case-sensitive. An entry for lfg also matches LFG.
  • An entry must match a full word. An entry for fr does not change the word "friend".
  • The dictionary does not change text inside a link.
  • The dictionary changes each word one time. TTS does not scan replaced text for more entries.

Your Own Entries

Moderators can add entries with the !tts pronounce command or in the Web Dashboard. Custom entries are useful for channel names, game terms, and difficult words.

  • Your entry replaces a built-in entry that has the same word.
  • To stop a built-in entry, use !tts pronounce off <word>. To restore it, use !tts pronounce remove <word>.
  • A channel can have a maximum of 100 entries.

How To Stop It

The dictionary is active for all channels by default. To turn it off, disable Expand Chat Acronyms in the Web Dashboard. TTS then speaks short forms letter by letter.

TTS already speaks lol as "el oh el". This is standard behavior and requires no dictionary entry.

Profanity Filter

The profanity filter replaces rude words with milder words before TTS speaks them. For example, TTS speaks "what the fuck" as "what the freak". The filter is off until a moderator starts it.

How To Start It

Use !tts profanity on in chat, or set the "Profanity Filter" control to on in the Web Dashboard. Use !tts profanity status to see the state, the language, and the number of words in the list.

What It Does

  • The filter replaces a rude word with a milder word. It does not remove the message, and it does not make a bleep sound.
  • The filter replaces a slur with the word "slur". This replacement keeps the meaning of the slur out of the audio.
  • The filter also applies to short forms from the pronunciation dictionary. When the filter is on, TTS speaks lfg as "let's freaking go".
  • A word must match fully. The filter does not change the word "class".

Languages

The filter has word lists for all 40 languages that Language Boost supports. The filter uses the list for your channel language. If a viewer selects a different language for their own messages, the filter uses both lists. The filter always includes the English list, because the pronunciation dictionary is in English.

If your Language Boost is "Automatic", the filter uses the English list. The bot cannot identify the language of each message.

The English list is the largest. The lists for other languages are smaller. Slurs are in the English list only.

The profanity filter is not the same as the Banned Words list. Banned Words removes the full message. The profanity filter speaks the message, but with milder words.

Banned Words

The Banned Words feature stops WildcatTTS from speaking unwanted messages. If a chat message contains a banned word or phrase, TTS skips the message completely. The bot does not generate audio for skipped messages.

How It Works

  • Matching is not case-sensitive. If you ban "badword", TTS also catches "BadWord" and "BADWORD".
  • TTS matches parts of words. If you ban "spam", TTS also skips messages that contain "spammer" or "spammy".
  • You can ban multi-word phrases. For example, you can ban phrases such as "follow my link" or "free followers".
  • TTS ignores the username in replies. If a reply mentions a user with a banned word in their name, TTS does not skip the message.

Stream Events and Redemptions

The bot handles events and chat messages differently when a message contains a banned word:

  • Chat Messages: TTS skips the full message. No voice audio plays.
  • Resubscriptions: The bot announces the resubscription, but omits the attached viewer message.
  • Watch Streaks: The bot announces the streak count, but omits the attached viewer message.
  • Channel Point Redemptions: The bot announces the reward redemption, but omits the custom text input.
  • Custom Reward Policy: If a Channel Point reward has a content policy, the bot rejects redemptions that contain banned words.

How To Manage Banned Words

You can configure banned words in the Web Dashboard. Changes take effect immediately.

  1. Log in to the Web Dashboard at tts.wildcat.chat with your Twitch account.
  2. Scroll to the Banned Words / Phrases card below the Ignore List section.
  3. Type a word or phrase into the input field.
  4. Click Add, or press Enter on your keyboard.
  5. If you want to remove an entry, click Remove next to the word in the list.
Banned Words skips the full message. The Profanity Filter speaks the message with milder words. If a message contains words on both lists, TTS skips the message.

YouTube Live Chat Integration

WildcatTTS can read YouTube Live chat messages aloud into your OBS audio feed. If you stream to Twitch and YouTube at the same time, the bot reads messages from both chats into one audio source.

How It Works

  • Multi-streaming support: Messages from Twitch and YouTube play through the same OBS Browser Source without extra audio setup.
  • Background polling: If you turn on the feature before you start your YouTube stream, the bot waits and connects when you go live.
  • Heartbeat system: The bot sends regular heartbeat signals to keep the YouTube connection active during slow chat.
  • Unified formatting: Custom YouTube emotes, URLs, and channel default voice settings apply to YouTube messages automatically.

How To Enable YouTube TTS

You can configure YouTube TTS in the Web Dashboard. Changes take effect immediately.

  1. Log in to the Web Dashboard at tts.wildcat.chat with your Twitch account.
  2. Scroll to the YouTube Integration card.
  3. Turn on the Enable YouTube TTS switch.
  4. Enter your YouTube handle (for example, @yourchannel), Channel ID, or live Video URL.
  5. If your stream is already live, OBS begins speaking your YouTube chat messages immediately.

Speech-Friendly URL Reading

Chat messages often contain long web links with parameters and tracking codes. WildcatTTS simplifies links so they sound natural when spoken.

How It Works

  • By default, TTS replaces links with speech-friendly domain names. For example, TTS speaks a search link as "google dot com link".
  • TTS removes protocol prefixes such as "https://" and "www." before speaking the domain name.
  • TTS replaces hyphens, underscores, and dots with spaces and words so the domain sounds natural.

Read Full URLs Option

If you want TTS to speak entire URLs as typed, turn on the Read Full URLs switch in the Web Dashboard. When this switch is on, TTS speaks the full link without shortening.

Stream Events & Privacy Controls

WildcatTTS gives you granular control over stream event announcements and viewer privacy in the Web Dashboard.

Cheer Announcements & Cheermote Filtering

When a viewer cheers bits, TTS automatically strips cheermote names like Cheer100 or Party1 from the message. TTS only reads the viewer's custom message.

Use the Announce Cheers switch in the Web Dashboard to turn off the "User cheered bits" alert while continuing to read cheer chat messages.

Follower Privacy & Anonymization

To protect viewer privacy, turn on the Anonymize New Followers switch in the Web Dashboard. When active, TTS announces "Someone new just followed!" instead of speaking the viewer's username.

Watch Streaks & Pronoun Resolution

When a viewer hits a watch streak milestone, the bot announces the streak count. If the viewer attached a message, the bot checks pronouns.alejo.io to speak their pronouns (for example, "They said: ...").

Web Dashboard

  • Voice Preview: Test your voice settings before you go live.

Voice Calibration

Some voices are naturally louder or quieter than other voices. Voice Calibration lets you set volume multipliers for individual voices to balance audio levels.

  • Per-Voice Volume: Select a voice and assign a volume multiplier (0.1x to 10.0x). (Caution: Values over 1.0 can be loud)
  • Auto-Apply: When a viewer selects a calibrated voice, the bot applies the custom volume automatically.
  • Overrides: Calibrated voice volumes override the channel default volume setting.

OBS Browser Source Setup

Step 1: Add Browser Source in OBS

  1. In OBS, click the "+" icon under Sources
  2. Select "Browser"
  3. Name the source (for example, "WildcatTTS")
  4. Configure the source:
    • URL: Paste your unique TTS URL from the dashboard
    • Width/Height: Set 300x100 (size does not affect audio)
    • ✓ Control audio via OBS (must be checked)
    • Uncheck "Shutdown source when not visible" so audio plays consistently

Step 2: Enable Audio Monitoring

  1. Locate the audio mixer in OBS (bottom panel)
  2. Click the gear (⚙️) next to "WildcatTTS" → "Advanced Audio Properties"
  3. Set "Audio Monitoring" to:
    • Monitor and Output - You and your stream hear the audio
    • Monitor Only - Only you hear the audio (for testing)

Important: Make sure that the source is unmuted in your audio mixer and the volume is set appropriately.

Troubleshooting

  • Bot not responding to commands? Make sure that the bot is a moderator in your channel. Type /mod wildcatttsbot in your Twitch chat. The bot requires moderator permissions to read messages and send replies.
  • Bot not speaking? Make sure that TTS is enabled with !tts on in chat. Also check the active mode with !tts mode and permissions with !tts permission.
  • Bot not speaking in a specific language, or reading numbers in Chinese? Set Language Boost to your language with !tts language <language_name> (or !tts defaultlanguage <language_name> for the channel). Show the active setting with !tts defaultlanguage.
  • TTS generation taking too long or failing? The bot uses 302.ai with automatic fallback to Wavespeed AI. If audio delays occur, use !tts stop to cancel stuck generation. The bot retries failed requests automatically.
  • Emotion not working? The auto emotion is not supported. Use neutral, happy, sad, angry, fearful, disgusted, or surprised.
