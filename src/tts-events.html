Stream Events & Privacy Controls

WildcatTTS gives you granular control over stream event announcements and viewer privacy in the Web Dashboard.

Cheer Announcements & Cheermote Filtering

When a viewer cheers bits, TTS automatically strips cheermote names like Cheer100 or Party1 from the message. TTS only reads the viewer's custom message.

Both switches are in the Cheers card of the Web Dashboard. Announce Cheers turns the "User cheered bits" alert on or off. Read Cheer Messages turns reading the attached message on or off. Cheer messages are read in every TTS mode and are not limited by TTS Permission, because the viewer paid for them.

Reward Announcements & Queued Redeems

When a viewer redeems a channel point reward, TTS speaks an alert with the reward title and the viewer message.

Use the Announce Reward Redeems switch in the Web Dashboard to turn redemption alerts on or off.

To keep one reward silent, for example a soundboard that plays its own sound, use Rewards to Announce in the Web Dashboard. Select Choose rewards and switch off the reward. The bot announces all other rewards. Moderators can use the !tts redeems mute command in chat.

By default, the bot announces a queued reward immediately when a viewer redeems it. Switch off Announce Queued Redeems Immediately to announce a queued reward only after you accept it in Twitch.

Follower Privacy & Anonymization

To protect viewer privacy, turn on the Anonymize New Followers switch in the Web Dashboard. When active, TTS announces "Someone new just followed!" instead of speaking the viewer's username.

Watch Streaks & Pronoun Resolution

When a viewer hits a watch streak milestone, the bot announces the streak count. If the viewer attached a message, the bot checks pronouns.alejo.io to speak their pronouns (for example, "They said: ...").

Chat Commands from Other Bots

Many channels run a second bot, for example Nightbot or StreamElements. Viewers control it with commands that start with "!", such as !lurk, !so or !sr. In All Chat Messages mode, WildcatTTS reads these commands aloud as chat.

Read Chat Commands Option

To skip these messages, switch off Read Chat Commands in the Web Dashboard, or type !tts readcommands off in chat. TTS then ignores every chat message that starts with "!".

  • !tts is not affected. !tts <text> is still spoken, and the other !tts commands still work.
  • The option applies only in All Chat Messages mode. The other modes never read these messages.
  • A cheer whose message starts with "!" is still read, because the viewer paid for it.

Speech-Friendly URL Reading

Chat messages often contain long web links with parameters and tracking codes. WildcatTTS simplifies links so they sound natural when spoken.

How It Works

  • By default, TTS replaces links with speech-friendly domain names. For example, TTS speaks a search link as "google dot com link".
  • TTS removes protocol prefixes such as "https://" and "www." before speaking the domain name.
  • TTS replaces hyphens, underscores, and dots with spaces and words so the domain sounds natural.

Read Full URLs Option

If you want TTS to speak entire URLs as typed, turn on the Read Full URLs switch in the Web Dashboard. When this switch is on, TTS speaks the full link without shortening.
