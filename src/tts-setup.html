Web Dashboard

The WildcatTTS Web Dashboard lets broadcasters configure all TTS settings. Sign in with your Twitch account to access the dashboard.

Available Dashboard Settings

  • Engine Control: Turn TTS on or off, announce stream events, and set TTS mode and permissions.
  • Viewer Preferences: Allow viewer custom voices, or force the channel default voice for all messages.
  • Allow Viewer Voice Preferences: Allow viewers to choose custom voices with !myvoice, or lock TTS to the channel default voice.
  • Bot Responds in Chat: Turn chat text replies on or off while keeping TTS voice audio active.
  • Page Language: Select the language of the dashboard text. The selector is at the top of the page. This selector does not change the voice or the announcements.
  • Anonymize New Followers: Announce new followers without speaking usernames for viewer privacy.
  • Announce Cheers: Turn cheer alerts on or off while continuing to read cheer messages.
  • Announce Reward Redeems: Turn channel point reward redemption alerts on or off.
  • Rewards to Announce: Select the rewards that the bot announces. Switch off a reward that plays its own sound.
  • Announce Queued Redeems Immediately: Announce queued channel point rewards immediately without waiting for approval.
  • Read Full URLs: Read full web links or only domain names.
  • Read Chat Commands: Read or skip chat messages that start with "!" in All Chat Messages mode. !tts always works.
  • Cheers: Announce cheers, read the message attached to a cheer, and set the minimum Bits a cheer needs.
  • Channel Points → TTS: Create and configure a custom Channel Point reward for TTS.
  • YouTube Integration: Enable YouTube Live chat TTS and set your YouTube handle or stream URL.
  • Ignored Users: Manage the TTS ignore list, banned words, and pronunciation dictionary.
  • Banned Words / Phrases: Block specific words or phrases so TTS skips matching messages.
  • Default Voice Settings: Set channel defaults for voice, volume, emotion, pitch, speed, language, and text normalization.
  • Voice Calibration: Set volume multipliers for individual voices to balance audio levels.
  • OBS Browser Source Setup: Get your secure OBS browser source URL and setup instructions.
  • Voice Preview: Test your voice settings before you go live.

Voice Calibration

Some voices are naturally louder or quieter than other voices. Voice Calibration lets you set volume multipliers for individual voices to balance audio levels.

  • Per-Voice Volume: Select a voice and assign a volume multiplier (0.1x to 10.0x). (Caution: Values over 1.0 can be loud)
  • Auto-Apply: When a viewer selects a calibrated voice, the bot applies the custom volume automatically.
  • Overrides: Calibrated voice volumes override the channel default volume setting.

OBS Browser Source Setup

Step 1: Add Browser Source in OBS

  1. In OBS, click the "+" icon under Sources
  2. Select "Browser"
  3. Name the source (for example, "WildcatTTS")
  4. Configure the source:
    • URL: Paste your unique TTS URL from the dashboard
    • Width/Height: Set 300x100 (size does not affect audio)
    • ✓ Control audio via OBS (must be checked)
    • Uncheck "Shutdown source when not visible" so audio plays consistently

Step 2: Enable Audio Monitoring

  1. Locate the audio mixer in OBS (bottom panel)
  2. Click the gear (⚙️) next to "WildcatTTS" → "Advanced Audio Properties"
  3. Set "Audio Monitoring" to:
    • Monitor and Output - You and your stream hear the audio
    • Monitor Only - Only you hear the audio (for testing)

Important: Make sure that the source is unmuted in your audio mixer and the volume is set appropriately.
