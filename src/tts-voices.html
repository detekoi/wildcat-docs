Language Boost

The language_boost feature improves pronunciation for specific languages and dialects. This setting helps in multilingual chats and non-English streams.

Set a personal language preference with !tts language <language_name>. Moderators can set a channel default with !tts defaultlanguage <language_name>.

Available Language Boost Options

The following values are accepted:

  • auto
  • Afrikaans
  • Arabic
  • Bulgarian
  • Catalan
  • Chinese
  • Chinese,Yue
  • Croatian

The auto setting uses automatic language detection. For English chats, set English. Selecting a specific language improves pronunciation for that language.

Announcements and Chat Replies

The channel language also selects the language of the text that the bot writes. This text includes stream event announcements, emote descriptions, and chat replies to commands.

For example, a viewer subscribes to a Spanish channel. The bot then makes the announcement in Spanish.

A personal language from !tts language changes the voice for your own messages only. A personal language does not change the announcements, because the whole channel hears them. The auto setting names no language, so a channel on auto gets announcements in English.

Automatic Detection

WildcatTTS reads the language that your channel declares on Twitch. The bot then sets the channel default for you.

The bot changes this setting only for a channel that has no language of its own. Your own choice always stays. Twitch has some languages that the voice engine does not support. For these languages, the channel stays on auto.
