Voices

WildcatTTS uses the Gemini speech model from Google. You can select from more than 2,000 voices. Each voice has a voice ID, which is the name that you type in a command.

To select a voice for your own messages, type !tts voice <voice_id> in chat. You can also select a voice on your personal settings page, which !tts prefs opens. Moderators set the voice of the channel with !tts defaultvoice <voice_id> or in the Web Dashboard.

WildcatTTS replaced the earlier MiniMax voices with Gemini voices. The bot changed each saved voice to the nearest new voice automatically. You do not have to select a voice again, but the new voice sounds different from the old voice.

Language

The speech model finds the language of each message by itself, and it supports more than 100 languages. The Language setting is a hint for text that gives the model too little information, such as a number or a very short message. The earlier name of this setting was Language Boost.

Set a personal language preference with !tts language <language_name>. Moderators can set a channel default with !tts defaultlanguage <language_name>.

With auto, the model selects the language from the text of each message. If your chat uses one language, set that language. The voice then reads numbers and short messages in that language.

Announcements and Chat Replies

The channel language also selects the language of the text that the bot writes. This text includes stream event announcements, emote descriptions, and chat replies to commands.

For example, a viewer subscribes to a Spanish channel. The bot then makes the announcement in Spanish.

A personal language from !tts language applies to your own messages only. A personal language does not change the announcements, because the whole channel hears them. The auto setting names no language, so a channel on auto gets announcements in English.

The channel language also selects the word list of the profanity filter. See Profanity Filter.

Channel Language From Twitch

WildcatTTS reads the language that your channel declares on Twitch. The bot then sets the channel default for you.

The bot changes this setting only for a channel that has no language of its own. Your own choice always stays. Twitch has some languages that are not in the list above. For these languages, the channel stays on auto.
