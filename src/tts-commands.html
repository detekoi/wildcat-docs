All TTS commands start with !tts.
For example: !tts status
Select any command row below to show usage details.
Broadcasters and viewers can also change settings in the WildcatTTS Web Dashboard.
Viewers can set personal TTS preferences in the web dashboard with !myvoice in chat.

Mod!tts mode [all|command|bits_points_only|highlighted_only]
!tts mode all (Reads all chat messages)
!tts mode command (Reads !tts messages; default mode)
!tts mode bits_points_only (Reads only cheers and the TTS reward)
!tts mode bits (Alias for bits_points_only)
!tts mode points (Alias for bits_points_only)
!tts mode highlighted_only (Reads Twitch "Highlight My Message" messages)
!tts mode highlight (Alias for highlighted_only)
!tts mode (Shows current mode)

Notes: In every mode, TTS reads cheers (see !tts bits), the TTS Channel Points reward, and enabled reward announcements and events. The mode sets which chat messages TTS also reads. The Web Dashboard name of each mode is in parentheses.
all (All Chat Messages): TTS reads all chat messages (except ignored users), based on !tts permission. This includes !tts <message>.
command (!tts Messages): TTS reads !tts <message>, based on !tts permission. TTS ignores other chat.
bits_points_only (Cheers and Rewards Only): TTS reads no chat messages. TTS ignores regular chat, !tts <message> and highlighted messages. This mode always reads cheer messages, also after !tts bits off.
highlighted_only (Highlighted Messages): TTS reads chat messages that a viewer sends with the Twitch "Highlight My Message" Channel Points reward. !tts permission does not apply to these messages, because the viewer paid for them. TTS ignores other chat and !tts <message>. On YouTube, this mode works like bits_points_only.

Permission: Moderator
Mod!tts permission [everyone|all|subs|vip|mods]
!tts permission everyone
!tts permission subs
!tts permission vip
!tts permission mods
!tts permission (shows the current permission filter)

Notes: everyone or all: TTS speaks messages from all users (Default).
subs: TTS speaks messages from subscribers, VIPs, moderators, and the broadcaster.
vip: TTS speaks messages from VIPs, moderators, and the broadcaster.
mods: TTS speaks messages only from moderators and the broadcaster.
This setting also applies to !tts <message> in command mode. Cheers and Channel Point redemptions are paid for and are not affected.

Permission: Moderator
Mod!tts bits [on|off|min <amount>]
Mod!tts bits on
Mod!tts bits off
Mod!tts bits min 100
Mod!tts bits (shows the current cheer settings)

Description:

  • on: Read cheer messages. This is the default.
  • off: Do not read cheer messages. Has no effect in bits_points_only mode, which always reads them.
  • min <amount>: Sets the minimum Bits a cheer needs for its message to be read (for example, min 100). The default is 1. Cheer messages are read in every mode and are not limited by !tts permission.

Permission: Moderator

Channel Points → TTS (Web Dashboard Only)
Channel Points → TTS

Note: This feature is configured exclusively through the WildcatTTS Web Dashboard under the "Channel Points → TTS" section.

How It Works:

  1. Streamer Setup: Turn on the feature in the dashboard.
  2. Reward Creation: The bot creates a custom Channel Point reward on your Twitch channel.
  3. Viewer Redemption: Viewers redeem the reward with a message that TTS speaks.
  4. Content Policy: Filter text with length limits, link blocking, and banned words.

Configuration Options:

  • Basic Settings: Reward title, cost in points, prompt text, and queue settings.
  • Advanced Settings: Global cooldown, stream limit, and user limit.
  • Content Policy: Minimum and maximum message length, link blocking, and banned words.

Skip the Reward Queue:

  • Default Setting: This option is on by default for immediate TTS playback.
  • When On: TTS approves each redemption and plays it at once. You do not need to review it.
  • When Off: Redemptions wait in your Twitch dashboard for manual approval before TTS plays.
  • Tip: Turn on for instant playback. Turn off for moderation review before audio plays.
  • Refunds: TTS refunds a redemption that it does not play. These redemptions get a refund: a message that the content policy blocks, a viewer that a moderator muted in your channel, and any redemption while TTS is off.

TTS Modes: Works in every TTS mode: All Chat Messages, !tts Messages, Highlighted Messages, and Cheers and Rewards Only.

Requirements: Grant channel:manage:redemptions and channel:read:redemptions permissions during dashboard sign-in.

Permission: Streamer/Broadcaster (via Web Dashboard)

Emote Description Management (Moderator Only)

Mod!tts emote <emoteName>
Usage:
Mod!tts emote LUL (shows the current cached description)
Mod!tts emote regenerate LUL (clears cache; AI will re-describe on next use)
Mod!tts emote set LUL = a person laughing (sets a custom description — channel emotes only)

Description:

  • Show the current AI description for an emote.
  • Clear the cached description so AI creates a new description on next use.
  • Set a custom description for a channel emote.

Notes: When an emote appears in chat for the first time, AI generates a text description. The bot caches descriptions permanently. Use this command to view, change, or regenerate emote descriptions.

Permission: Moderator (set/regenerate only for channel emotes)

Pronunciation & Filtering (Moderator Only)

Mod!tts pronounce <word> = <how to say it>
Usage:
Mod!tts pronounce wcat = wildcat (adds or changes an entry)
Mod!tts pronounce list (shows the entries for this channel)
Mod!tts pronounce remove wcat (removes an entry)
Mod!tts pronounce off lfg (stops a built-in entry)
Mod!tts pronounce test ngl that was wild (shows the result without speaking)
Mod!tts pronounce defaults (lists the built-in entries)

Description:

  • Add a word and the text that TTS speaks in its place. Your entry replaces a built-in entry with the same word.
  • Remove your entry. If a built-in entry has the same word, that built-in entry becomes active again.
  • Stop a built-in entry. To start it again, use the remove sub-command.
  • Show what TTS will say for some text. The bot does not speak the text.
  • The broadcaster can use !tts pronounce clear to remove all entries for the channel. Built-in entries stay active.

Notes: The word is not case-sensitive, and it must match a full word. A channel can have a maximum of 100 entries. A word can have a maximum of 40 characters. A spoken form can have a maximum of 120 characters. You can also change these entries in the Web Dashboard.

Permission: Moderator (broadcaster only for clear)
Mod!tts profanity <block|allow|status>
Usage:
Mod!tts profanity block (starts the filter)
Mod!tts profanity allow (stops the filter)
Mod!tts profanity status (shows the state, the language, and the number of words)

Notes: The filter is off until you start it. It replaces rude words with milder words. It does not remove the message. The Banned Words list in the Web Dashboard removes a full message. The older on and off words still work: on is the same as block.

Permission: Moderator
Mod!tts redeems <mute|unmute|list|all>
Usage:
Mod!tts redeems mute <reward title> (stops the announcements for one reward)
Mod!tts redeems unmute <reward title> (starts the announcements again)
Mod!tts redeems list (shows the muted rewards)
Mod!tts redeems all (shows all rewards on the channel)

Notes: The bot announces every reward until you mute it. Use this command for a reward that plays its own sound, for example a soundboard. You can type a part of the title. If more than one reward matches, the bot shows the names and asks for the full name. The reply always shows the name of the reward that changed. The bot cannot mute the TTS reward. This command works only when the broadcaster is signed in to the Web Dashboard. You can also select the rewards in the Web Dashboard, under Rewards to Announce.

Permission: Moderator
Mod!tts readcommands <on|off>
Usage:
Mod!tts readcommands off (skips chat messages that start with "!")
Mod!tts readcommands on (reads them again)
Mod!tts readcommands (shows the current setting)

Notes: Other bots, for example Nightbot or StreamElements, use commands that start with "!", such as !lurk or !so. In All Chat Messages mode, TTS reads these commands as chat. Switch this setting off to skip them. The setting does not change !tts: !tts still works. The setting has no effect in !tts Messages, Highlighted Messages or Cheers and Rewards Only mode, because these modes never read these messages. A cheer that starts with "!" is still read, because the viewer paid for it. You can also change this in the Web Dashboard, under Read Chat Commands.

Permission: Moderator
