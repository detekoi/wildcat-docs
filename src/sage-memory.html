Channel Memory

With Channel Memory, WildcatSage remembers facts about your community from one stream to the next. Examples are running jokes, words with a special meaning in your channel, and facts about regular viewers. Channel Memory is on by default.

How the Bot Learns

The bot learns in two ways:

  • From chat: The bot reads chat in groups of messages. It stores the facts that the community will use again. Most groups contain no such facts.
  • From moderators: A moderator teaches a fact with !remember.

A fact from a moderator has priority. A fact from chat cannot replace it.

The bot uses Gemini Flash Lite to read chat. This is the same model that does translation.

The bot does not read these messages for Channel Memory:

  • Messages from the bot
  • Messages that start with !
  • Messages from viewers who used !forgetme

What the Bot Stores

The bot stores these types of facts:

  • A word or phrase that has a special meaning in your channel
  • Running jokes and nicknames
  • Harmless facts about regular viewers, for example the character that a viewer plays
  • Facts that chat tells the bot to remember

The bot does not store greetings, short reactions, or comments about the current game.

The instructions for the AI model exclude sensitive personal details, such as health, addresses, real names, age, and finances.

An AI model can make errors. A moderator can delete an incorrect memory with !forget.

How the Bot Uses Memories

When a viewer mentions the bot or uses !ask, the bot compares the message with the stored memories. If a memory matches, the bot uses the memory in its reply.

The comparison uses the words in the message. If a viewer uses different words for the same subject, the bot can fail to find the memory.

If the bot has no memory about a subject, the bot says that it does not remember.

Privacy and Opt-Out

A moderator can disable Channel Memory with !memory off. The bot then does not read chat for Channel Memory and does not use the stored memories. The stored memories stay. !memory on enables Channel Memory again.

Each viewer can use !forgetme. The bot deletes the memories about that viewer. After that, the bot does not read the messages of that viewer for Channel Memory. This command applies to one channel only.

Memories belong to one channel. The bot does not share memories between channels.

WildcatSage uses a paid Gemini API key. Google does not use chat messages, prompts, or memories to train AI models.

Maximum memories for each channel 300
