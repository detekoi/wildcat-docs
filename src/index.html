AI-Powered Twitch Bot Platform

Bot Documentation

Welcome to Wildcat.chat! This platform provides AI-powered chat bots and TTS services for Twitch streamers.

WildcatSage Bot

AI-powered chatbot with contextual responses, web search, games, and more.

  • Ask questions and get AI responses
  • Web search integration
  • Interactive games (trivia, geo-game, riddles)
  • Auto-chat and translation features

WildcatTTS Bot

Advanced Text-to-Speech bot with music generation capabilities.

  • Natural-sounding TTS with 300+ voices
  • Channel points integration
  • AI music generation
  • Web dashboard for settings

Chat Overlay

A customizable Twitch and YouTube chat overlay with AI-generated themes for OBS.

  • Supports Twitch and YouTube live chat
  • AI-generated themes using natural language
  • Easy OBS browser source integration
  • Chat Scene creator for multiple profiles

Getting Started

Quick Start

  1. Visit bot.wildcat.chat to set up your WildcatSage bot
  2. Visit tts.wildcat.chat for WildcatTTS dashboard
  3. Authenticate with your Twitch account
  4. Configure your bot settings
  5. Check the documentation pages for detailed command references
