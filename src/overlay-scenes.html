Chat Scene Creator

With the Chat Scene Creator, you can make and manage named overlay scenes for different stream layouts (for example, Gaming or Just Chatting).

Key Features

  • Scene Management: Create, duplicate, and delete scenes. Import and export JSON scene files. Link an existing scene with its sync token.
  • Channel Connection: Enter a Twitch channel, or a YouTube channel ID or handle. The change applies immediately.
  • Visual Settings: Set Google Fonts, preset themes, AI themes, custom theme presets, colors, background images, opacities, chroma key, popup layouts, badges, and emote filters.
  • Interactive Live Preview: Test your settings in a live preview box. Set the preview background to Dark, Light, Grid (Checkerboard), or a custom color. Each change shows in the preview immediately.

Automatic Live Sync

The Chat Scene Creator adds a unique sync token to your OBS URL: chat.html?scene=NAME&sync=TOKEN. When you save a change on the web, the OBS browser source updates live. You do not need to refresh the page.

If you change settings in OBS, the settings save locally in the cache of the OBS browser source.

Export and Import Scene Files

You can back up or move chat scene settings with JSON files.

  • Export Single Scene: To export one scene, select the scene. Then click Export.
  • Export All Scenes: To back up all scenes, click Export All in the left panel.
  • Import Scene File: To restore scene settings, click Import. Then select a saved JSON file on your computer.

Link an Existing Scene (Sync Token)

You can link an existing cloud-synced scene to a new browser or computer with its sync token.

  1. Click Link Scene in the left panel.
  2. Enter the sync token from your OBS URL (the alphanumeric token after sync=).
  3. Click Link to get the scene settings from the cloud. When you save a change on any device, the linked scene updates live.

Config Panel Features

In OBS, right-click the Browser Source. Then select Interact to open the config panel. The panel has these options:

  • Channel Selection: Select Twitch or YouTube. Then enter your channel information to connect.
  • Font Settings: Search Google Fonts, set the font size, and set the font weight.
  • Display Layout: Select Window mode or Popup mode. Set background colors, opacities, borders, and shadows.
  • Message Elements & Events: Show or hide platform badges, user badges, super chats, membership events, pronouns, and timestamps. Turn on single emote enlargement and the top gradient fade.
  • Emotes & Safety: Turn on third-party emotes and set the 7TV content filters.
  • Theme Management: Select a preset theme, generate an AI theme, save a custom theme preset, and set custom hex colors.
  • Hide Commands: Hide chat messages that start with !. Read Hide Command Messages for more information.

Hide Command Messages

Viewers send bot commands as chat messages that start with !, for example !so or !lurk. The Hide Commands option keeps these messages off your overlay.

The option is in the Message Elements group of the config panel and of the Chat Scene Creator. It is off by default.

The option applies to normal chat messages only. A super chat or a membership event that starts with ! still shows.
