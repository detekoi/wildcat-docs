General
!ask / !sage
!ask <question>
Features:
  • Time Queries: Ask for the current time in any location and language.
  • Examples: "what time is it in Tokyo?", "quelle heure est-il à Paris?", "che ora è a Roma?", "東京は何時ですか？"
  • Supported Languages: English, Spanish, Portuguese, German, French, Italian, Russian, Japanese

!game
Modes:
!game - Shows current game information and facts.
!game analyze - Uses AI to inspect stream visuals and describe gameplay.
!game <question> - Answers questions about the current game.
!game analyze <question> - Inspects stream visuals and answers your question.
Image Analysis Features:
  • Uses Twitch stream thumbnails (updates every 5 minutes).
  • AI inspects in-game elements and ignores stream overlays.
  • Web search confirms accurate descriptions.
  • Summarizes long responses automatically.

!quote
!quote Shows a random quote
!quote <id> Shows a quote by ID number (for example: !quote 12)

!quote <search term> Searches quotes by text or author (for example: !quote parfait)

!quote add <text [- author]> Adds a new quote. Add an author after " - " (for example: !quote add "hello world - parfait")
Mod!quote delete <id> Deletes a quote (moderators and broadcaster only)
Mod!quote edit <id> <text [- author]> Edits a quote (moderators and broadcaster only)
!followage
!followage Shows your own follow time
!followage <username> Shows another user's follow time
!so Mod
Mod!so <username> Posts a message about the streamer, with a link to their channel, and sends a Twitch Shoutout
The AI writes the message from the game, the stream title, the tags, the bio and the pronouns of the streamer. If the AI is off or fails, the bot posts a fixed message that names the game
Twitch sends a Shoutout only while your stream is live. Twitch sends one Shoutout every 2 minutes at most, and one Shoutout to the same streamer every 60 minutes at most. The bot posts the chat message each time
You can turn off the AI message and the Twitch Shoutout in the Web Dashboard

Custom Commands
!command Mod
Mod!command add <name> <response> Creates a new text command
Mod!command addai <name> <prompt> Creates a new AI command that generates a unique response from a prompt
Mod!command edit <name> <response> Updates a command response
Mod!command remove <name> Deletes a command
Mod!command show <name> Shows the response template and settings for a command
Mod!command options <name> permission=<level> Sets required permission: everyone, subscriber, vip, moderator, or broadcaster
Mod!command options <name> cooldown=<seconds> Sets a cooldown between uses in seconds
Mod!command options <name> type=<text|prompt> Switches a command between text mode and AI mode
!timer Mod
Mod!timer add <name> <interval> <response> Creates a new text timer with the given interval in minutes
Mod!timer addai <name> <interval> <prompt> Creates a new AI timer with the given interval in minutes
Mod!timer edit <name> <response> Updates a timer response
Mod!timer interval <name> <minutes> Sets the minimum interval in minutes between timer messages
Mod!timer lines <name> <number> Sets the minimum number of chat lines between timer messages
Mod!timer enable <name> Enables a paused timer
Mod!timer disable <name> Pauses an active timer
Mod!timer remove <name> Deletes a timer
Mod!timer show <name> Shows the settings for a specific timer
Mod!timer list Shows all timers for the channel

Channel Memory
!remember Mod
!remember <fact> Stores the fact (for example: !remember gary = the rubber duck on the desk)
If a memory with the same phrase exists, the new text replaces the old text
!forget Mod
!forget <phrase> Deletes each memory that contains the phrase (for example: !forget gary)
The phrase must have 3 characters or more
!forgetme
!forgetme Deletes the memories about you. This command applies to the current channel only
!memory Mod
!memory Shows the setting and the number of stored memories
!memory off Disables Channel Memory. The stored memories stay, but the bot does not use them
!memory on Enables Channel Memory

Games
!geo
!geo Starts a real-world game with locations across the world
!geo <region> Starts a game in a specific region (for example: !geo Japan)
!geo game Starts a game using locations from the current stream game
!geo game [Game Title] Starts a game using a specified game title (for example: !geo game "Metroid Prime")
!geo <command> N Runs a game with a set number of rounds (for example: !geo Japan 3)
!geo leaderboard
!geo stop Stops the game (game starter, moderators, or broadcaster)
Mod!geo config difficulty <easy|normal|hard>
Mod!geo config interval <seconds> Sets the delay between clues (30 to 300 seconds)
Mod!geo config duration <minutes> Sets the round duration (3 to 20 minutes)
Mod!geo config region <regions> Sets default regions (for example: Europe,Asia or USA,Canada)
Mod!geo config game <titles> Sets preferred game titles as a comma-separated list
Mod!geo config pointsbase <number> Sets base points per round (1 to 100)
Mod!geo config pointstimebonus <true|false>
Mod!geo config pointsdifficultymultiplier <true|false>
Mod!geo config scoretracking <true|false>
Mod!geo config maxrounds <number> Sets maximum rounds per game (1 to 10)
Mod!geo resetconfig
Mod!geo clearleaderboard Alias: !geo resetstats
!geo report <reason> Reports incorrect locations or clues
!geo help
