Troubleshooting

  • Bot not responding to commands? Make sure that the bot is a moderator in your channel. Type /mod WildcatTTS in your Twitch chat. The bot requires moderator permissions to read messages and send replies.
  • Bot not speaking? Make sure that TTS is enabled with !tts on in chat. Also check the active mode with !tts mode and permissions with !tts permission.
  • Numbers or short messages in the wrong language? The voice finds the language from the text of each message. A number or a very short message gives too little text. Set the language with !tts language <language_name> (or !tts defaultlanguage <language_name> for the channel). To see the active setting, use !tts defaultlanguage.
  • TTS generation taking too long or failing? The audio usually starts about half a second after the bot gets the message. If the speech model fails, the bot tries again automatically. If a message stays in the queue and does not play, use !tts stop to cancel it.
  • Emotion not working? Use neutral, happy, sad, angry, fearful, disgusted, surprised, calm, or fluent. A custom style replaces the emotion. To use the emotion again, remove the style with !tts style off (or !tts defaultstyle off for the channel).
  • Voice sounds different from before? WildcatTTS replaced its earlier voices with Gemini voices. The bot changed each saved voice to the nearest new voice, so the voice does not sound the same. To select a different voice, search the voice list.
  • Voice laughs, sighs, or sounds different from message to message? This behavior is normal. The new voices read chat more like a person. The voice can turn "lol" or "lmao" into a real laugh, and it sometimes adds a small laugh or a sigh. The same voice also changes a little from message to message. The voice can read a message that is only "?" as "What?".
  • Voice screams, coughs, or makes other sounds? A viewer typed a sound tag such as <scream>. Moderators can turn a tag off with !tts tags off <tag>. See Sound Tags.
  • Speed or pitch not exact? Speed and pitch have five steps each. The result is approximate, because the bot tells the voice in words how to speak. The volume is exact.
  • One message skipped without a reason? The speech model from Google has a content filter. If the content filter refuses a message, the bot skips that message and gives no error. The bot also skips a message that contains a banned word, and messages from ignored users.
  • Is a refresh of the OBS browser source necessary? No. A browser source from before the change to the Gemini voices continues to work. If you refresh the browser source one time, the audio starts sooner.
