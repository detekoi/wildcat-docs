Wildcat Chat Overlay

Overview

The Wildcat Chat Overlay shows Twitch and YouTube Live chat messages in OBS Studio. You can change its settings in the Chat Scene Creator on the web, or in the config panel of the OBS browser source.

Get Started with the Chat Overlay

Platform Support

The overlay connects to Twitch and to YouTube. You select the platform in the config panel.

  • Twitch: Enter your channel name (for example, wildcatgamer). Badges and emotes load automatically.
  • YouTube: The overlay supports YouTube live chat for public and unlisted streams. For a public stream, enter your channel username, channel ID, video URL, or video ID. For an unlisted stream, enter the video URL. Private streams are not supported.

Customization & Themes

You can change the look of the overlay in the config panel or in the Chat Scene Creator.

Configuration Options: There are two ways to change the settings:
  1. Web Chat Scene Creator (Recommended): Set channel connections, fonts, themes, colors, and layouts on the web. The Chat Scene Creator sends each saved change to OBS live.
  2. OBS Config Panel: In OBS, right-click the Browser Source. Then select Interact. Move the pointer over the chat. Then click the settings gear (). Settings that you change here stay local to this OBS source.
  3. The overlay saves the settings of each scene source automatically.

Automatic AI Themes

The overlay has an AI theme generator. In the config panel, type a description of the look that you want (for example, "cyberpunk neon night" or "cozy wooden cabin"). The overlay makes the CSS variables, adjusts the color contrast, sets matching pronoun badge colors, and applies the theme live.

Theme Carousel & Custom Themes

Use the theme carousel to select a preset theme, an AI theme, or a custom theme. The carousel stores up to 50 saved themes. You can delete a custom theme. The overlay asks you to confirm the deletion. The active theme is the same on every page.

Custom Theme Presets

You can save your current visual settings as a named theme preset. You can save a preset from the Chat Scene Creator or from the config panel. Presets go to the cloud theme carousel.

  • Cloud Sync & Deletion: The overlay removes duplicate presets, backs them up to the cloud, and lets you delete them.
  • Background Image Support: In the Chat Scene Creator, a preset saves your uploaded background image. In the config panel, a preset uses the background image of the active theme.

Color Customization

You can set the color of every chat element. Enter a hex color code (for example #FF5500). Swatches show your current colors. For a transparent background, enter transparent or a hex code with an alpha value.

Tip: Search the web for "color picker" to find an interactive color tool. Copy the hex code and paste it into the settings field.

Available Color Settings

  • Background Color: The main background of chat messages. Use it with the background opacity slider to control transparency.
  • Border Color: The border around chat message bubbles.
  • Text Color: The color of chat message text.
  • Username Color: The default color of usernames. Turn on Override User Colors to apply your color to all usernames.
  • Timestamp Color: The color of the message timestamps.
  • Pronoun Badge Color: The color of the pronoun badge next to a username. You can set it to the timestamp color.
  • Background Opacity: Sets the opacity of the message background, from 0% (fully transparent) to 100%.
  • Background Image Upload & Opacity: Upload a background image in the Chat Scene Creator. Set its opacity with the background image opacity slider.
  • Chroma Key Mode: Sets a solid green background for green screen keying in OBS.

Google Fonts & Typography

You can set the font style, the font size, and the layout limits to match your stream layout.

Searchable Google Fonts

Use the font picker to search Google Fonts and select one. The overlay loads the font stylesheet live in the preview and in OBS.

Typography & Layout Settings

  • Font Size: Sets the font size, from 10px to 40px.
  • Font Weight: Select Normal, Bold, 500, 600, 700, or 800 Extra Bold.
  • Border Radius: Select a border radius preset (0px, 8px, 16px, or 24px).
  • Box Shadow: Select a shadow depth preset (None, Soft, Simple 3D, Intense 3D, or Sharp).
  • Text Shadow: Select a text shadow preset (None, Soft, Sharp, Outline, Strong, or Glow).
  • Chat Dimensions: Sets the width (20% to 100%) and the height (20% to 100%) of the chat container.

Third-Party Emotes & Stacking

The overlay supports three third-party Twitch emote providers: BetterTTV (BTTV), FrankerFaceZ (FFZ), and 7TV. Global and channel emote sets load automatically for Twitch channels.

Zero-Width & Overlay Stacking

A zero-width emote (for example, a hat or a rain effect) stacks on the emote before it. Put a space between the two emotes (for example catJAM cvHazmat). You can chain zero-width emotes to make a stack with many layers. Single-emote enlargement also applies to a stacked emote.

Priority & Matching

An emote matches an exact, case-sensitive word. A Twitch emote has priority over a third-party emote. A channel emote has priority over a global emote.

Content Safety & Customization

You can change these third-party emote settings in the config panel:

  • Third-Party Emotes Toggle: The master switch that turns all third-party emotes on or off.
  • Show Channel Emotes: Shows or hides the third-party emotes of the channel.
  • 7TV Content Filters: Hide sensitive emotes by category (Twitch Disallowed, Sexual Content, Epilepsy / Flashing, and Edgy / Offensive).

Display Modes & Animations

Select Window mode (a continuous scrolling list) or Popup mode (message bubbles that disappear). Message entry and exit animations use the Web Animations API, so they stay smooth.

Popup Animation Directions & Controls

In Popup mode, you can set the entry direction of a message: From Bottom, From Top, From Left, or From Right. You can also set the message duration (2 to 60 seconds) and the maximum popup count (1 to 10). Popup messages stay visible while you change settings, so you can see the result.

Reduced Motion Support

The overlay obeys the prefers-reduced-motion setting of the system. When this setting is on, Window mode has no entry animation, and Popup mode uses the shortest transition.

Config Panel Features

In OBS, right-click the Browser Source. Then select Interact to open the config panel. The panel has these options:

  • Channel Selection: Select Twitch or YouTube. Then enter your channel information to connect.
  • Font Settings: Search Google Fonts, set the font size, and set the font weight.
  • Display Layout: Select Window mode or Popup mode. Set background colors, opacities, borders, and shadows.
  • Message Elements & Events: Show or hide platform badges, user badges, super chats, membership events, pronouns, and timestamps. Turn on single emote enlargement and the top gradient fade.
  • Emotes & Safety: Turn on third-party emotes and set the 7TV content filters.
  • Theme Management: Select a preset theme, generate an AI theme, save a custom theme preset, and set custom hex colors.
  • Hide Commands: Hide chat messages that start with !. Read Hide Command Messages for more information.

Hide Command Messages

Viewers send bot commands as chat messages that start with !, for example !so or !lurk. The Hide Commands option keeps these messages off your overlay.

The option is in the Message Elements group of the config panel and of the Chat Scene Creator. It is off by default.

The option applies to normal chat messages only. A super chat or a membership event that starts with ! still shows.

Chat Scene Creator

With the Chat Scene Creator, you can make and manage named overlay scenes for different stream layouts (for example, Gaming or Just Chatting).

Key Features

  • Scene Management: Create, duplicate, and delete scenes. Import and export JSON scene files. Link an existing scene with its sync token.
  • Channel Connection: Enter a Twitch channel, or a YouTube channel ID or handle. The change applies immediately.
  • Visual Settings: Set Google Fonts, preset themes, AI themes, custom theme presets, colors, background images, opacities, chroma key, popup layouts, badges, and emote filters.
  • Interactive Live Preview: Test your settings in a live preview box. Set the preview background to Dark, Light, Grid (Checkerboard), or a custom color. Each change shows in the preview immediately.

Automatic Live Sync

The Chat Scene Creator adds a unique sync token to your OBS URL: chat.html?scene=NAME&sync=TOKEN. When you save a change on the web, the OBS browser source updates live. You do not need to refresh the page.

If you change settings in OBS, the settings save locally in the cache of the OBS browser source.

Export and Import Scene Files

You can back up or move chat scene settings with JSON files.

  • Export Single Scene: To export one scene, select the scene. Then click Export.
  • Export All Scenes: To back up all scenes, click Export All in the left panel.
  • Import Scene File: To restore scene settings, click Import. Then select a saved JSON file on your computer.

Link an Existing Scene (Sync Token)

You can link an existing cloud-synced scene to a new browser or computer with its sync token.

  1. Click Link Scene in the left panel.
  2. Enter the sync token from your OBS URL (the alphanumeric token after sync=).
  3. Click Link to get the scene settings from the cloud. When you save a change on any device, the linked scene updates live.

URL Parameters

The overlay URL accepts query parameters. The Chat Scene Creator adds the scene and sync parameters for you. You can add the other parameters by hand.

Chat overlay URL parameters
Parameter What it does Example
scene Loads a named scene. If you omit this parameter, the overlay loads the scene named default. chat.html?scene=gaming
sync Links the browser source to a cloud-synced scene. Read Automatic Live Sync for more information. chat.html?scene=gaming&sync=TOKEN
demo Shows sample chat messages. The overlay does not connect to Twitch or YouTube in this mode. chat.html?demo=1
debug Shows status and diagnostic messages on screen. The overlay hides these messages by default. chat.html?scene=gaming&debug=1

Diagnostic Messages

The overlay hides all status messages by default. Connection notices and error text stay off your stream. The parameter debug=1 shows these messages on top of your chat.

The overlay always writes the same messages to the browser console. This applies with or without the debug parameter.

The connection status for Twitch and YouTube is in the config panel. In OBS, right-click the Browser Source. Then select Interact to see it. The status shows Connected, Connecting, Reconnecting, or Disconnected.

Remove debug=1 from the URL before you stream. The messages are visible to your viewers.

Demo Mode

The parameter demo=1 shows sample chat messages in a loop. The overlay does not connect to a chat platform, and it hides the connection prompt. The Chat Scene Creator uses this mode for the live preview.

OBS Setup Instructions

Do these steps to add the chat overlay to OBS Studio:

  1. In OBS Studio, open the Sources panel. Click +. Then select Browser.
  2. Enter a name for the source (for example, "Twitch Chat").
  3. Paste the URL from the Chat Scene Creator into the URL field. If you cannot paste the URL, clear the "Local file" checkbox.
  4. Set Width to 320 and Height to 600.
  5. Click "OK" to add the browser source to your canvas.
  6. Change the Settings: Save your settings in the Chat Scene Creator. They sync live to OBS. As an alternative, right-click the Browser Source in OBS. Then select Interact to change the settings locally.
  7. In the interactive window, enter your channel information. Click the settings gear (). Then click "Connect".

Advanced OBS Tips

  • Turn on Shutdown source when not visible to save system resources.
  • To hide the scrollbars, add body { overflow: hidden; } to the Custom CSS field.
  • Settings save to the OBS cache. If you clear the OBS cache for this source, set your visual settings again.
