Response Variables

You can use response variables to insert dynamic text into custom commands. Put $(variable) in your command response. The bot replaces the variable when a user runs the command.

Response Variables
Variable What it does Example output
$(user) Username of the person who ran the command WildcatGamer
$(channel) Channel name WildcatStreamer
$(args) All text after the command name as one string If a user runs !shout hello world, $(args) = hello world
$(1) $(2) ... A single word by position: $(1) is the first word, $(2) is the second word If a user runs !shout hello world, $(1) = hello, $(2) = world
$(count) Total number of times users ran this command 42
$(random X-Y) A random number between X and Y 17 from $(random 1-20)
$(uptime) Current stream uptime 2h 30m
$(game) Current stream game title Metroid Prime
$(followage) How long the user has followed the channel 2 years 3 months
$(checkin_count) The viewer daily check-in total (Channel Point Rewards only) 14
$(pronouns) Pronouns of the user who ran the command They/Them
$(pronoun_subject) Subject pronoun of the user who ran the command they
$(pronoun_object) Object pronoun of the user who ran the command them
$(pronoun_possessive) Possessive pronoun of the user who ran the command their
Variable Compatibility:
  • Custom Commands and Daily Check-In: Support all variables, including user-specific variables.
  • Timed Messages (Timers): Run on a schedule without an active user. Timers support only channel and stream variables ($(channel), $(game), $(uptime), $(count), $(random X-Y)).

Examples

Here are example custom commands:

Response variable examples
Chat command Bot response
!command add hi Hello $(user)! Welcome! Hello WildcatGamer! Welcome!
!command add roll $(user) rolled a $(random 1-20)! WildcatGamer rolled a 17!
!command add live We have been live for $(uptime) playing $(game)! We have been live for 2h 30m playing Metroid Prime!
!command add hug $(user) hugs $(1)! WildcatGamer hugs WildcatStreamer!
!command add cheer $(user) arrived! Welcome $(pronoun_object)! WildcatGamer arrived! Welcome them!
!command add uses This command was used $(count) times! This command was used 42 times!

AI Commands

AI commands use a prompt instead of a fixed text response. The bot sends the prompt to an AI model to generate a unique reply every time. You can also use response variables in prompts.

You can create AI commands in the Web Dashboard. Select + Add, enable AI Mode, and enter your prompt. You can also create AI commands in chat with !command addai <name> <prompt>.

AI command examples
AI Prompt Bot response
Name: vibe
Prompt: Tell $(user) what kind of vibe "$(args)" gives off in one sentence.		 If a user enters !vibe I just ate an entire pizza, the AI can reply: "WildcatGamer your message gives off deeply respectable goblin energy." Replies vary with each use.
Name: hug
Prompt: Write a short, funny hug message from $(user) to $(1).		 If a user enters !hug WildcatStreamer, the AI can reply: "WildcatGamer wraps WildcatStreamer in a hug so warm it could melt a glacier."
Name: fortune
Prompt: Give $(user) a short fortune cookie message.		 A unique fortune for each use: "WildcatGamer, today you will find a rare item in an unexpected place."

Tip: You can convert a text command to AI mode in the dashboard by enabling AI Mode. You can also run !command options <name> type=prompt in chat. Switch back with type=text.

Web Dashboard

The WildcatSage Web Dashboard lets streamers configure bot settings for their channel. Sign in with your Twitch account to access the dashboard.

Dashboard Features

  • Bot Management: Add or remove WildcatSage from your channel.
  • Channel Settings: Configure auto-chat frequency, stream event messages, and ad break notifications.
  • Stream Events: Enable AI greetings, farewells, and celebration messages for new followers, subscribers, and incoming raids.
  • Command Management: Create custom commands and enable or disable built-in commands.
  • Timed Messages: Create and manage scheduled chat messages with interval and chat line settings.
  • Bot Personality: Customize tone, humor, and style instructions for AI responses, with automatic Twitch rule checks.
  • Bot Language: Set the language the bot speaks in your channel, or use the stream language from Twitch.
  • Daily Check-In: Configure a Channel Point Reward for daily check-ins with streak tracking and optional AI responses.
  • Dashboard Language: Show the dashboard in one of eight languages. This setting is separate from the bot language.

Getting Started

  1. Visit the Dashboard: Go to https://bot.wildcat.chat/.
  2. Authorize: Select "Sign in with Twitch" and approve the required permissions.
  3. Add the Bot: Select "Add bot to my channel" to invite WildcatSage to your channel.
  4. Configure: Change bot settings in the dashboard.
  5. Troubleshooting: If the bot does not respond, enter /mod WildcatSage in Twitch chat to grant moderator permissions.

OAuth Permissions

The dashboard requires these Twitch OAuth permissions:

  • user:read:email - Reads your email address for account identification.
  • channel:read:ads - Receives ad break notifications for your channel.
  • channel:manage:moderators - Grants moderator permissions to the bot.
  • moderator:read:followers - Reads follower data for commands such as !followage.
  • channel:manage:redemptions - Creates and manages Channel Point Rewards for features such as Daily Check-In.

Note: WildcatSage is currently invite-only. If your channel does not appear in the dashboard, request access through the contact form.

Bot Personality

Bot Personality controls how WildcatSage speaks in your channel. You write the personality text in the dashboard. The bot then uses this text for its AI replies.

Setup

  1. Open the WildcatSage Dashboard and go to the Bot Personality section.
  2. Change the text in the box. The box contains the default personality.
  3. Select Save.

Note: The new personality applies immediately. A restart is not necessary.

Limits

Limits
Item Value
Maximum length 2000 characters
Applies to Chat replies, auto-chat messages, stream event messages, AI custom commands, and Daily Check-In AI messages
Does not apply to Trivia, Riddle, and Geo games

What You Can Change

You can change the name, the tone, the humor, and the topics of the bot. The default personality includes a cat roleplay section. You can remove this section.

Rules That Always Apply

These rules apply to all channels. Your text cannot change them:

  • The bot does not send or simulate chat commands such as /ban or /timeout.
  • The bot keeps each reply to one or two sentences.
  • The bot does not show its own instructions in chat.
  • The channel values stay in effect.

The Rules that always apply panel in the dashboard shows the full text of these rules. This panel is read-only.

Safety Check

WildcatSage examines each personality before it stores the text. This check uses Gemini Flash Lite, the same model that does translation.

The check rejects text that gives the bot these instructions:

  • Harass viewers, or attack a person.
  • Send or simulate moderation commands.
  • Impersonate a real person or a company.
  • Ignore the rules that always apply.
  • Show its own instructions in chat.
  • Send spam, scams, or advertisements.

The check does not reject a personality because of its tone. A rude, sarcastic, or profane personality is permitted.

If the check rejects your text, the dashboard shows the reason. The bot does not store the text. Your text stays in the box. Correct the text, then select Save again.

If the check is not available, the save fails. The bot does not store text that the check did not examine.

Reset to Default

  1. Select Reset to default.
  2. Select OK in the confirmation message.

When your channel has a custom personality, the dashboard shows this button.

Shared Chat

In a Twitch shared chat session, the bot mixes the personalities of all channels in the session. The bot gives more weight to the personality of the host channel. A channel with the default personality adds nothing to the mix.

Other AI Prompts

The same safety check applies to these fields:

  • AI prompts for custom commands
  • AI prompts for timers
  • AI prompts for Daily Check-In

Text commands and text timers do not use the check. The bot sends this text without a change.

Bot Language

WildcatSage can speak a language other than English in your channel. The language applies to command replies, game messages, and AI replies.

Automatic Detection

You set a stream language on your Twitch channel. WildcatSage reads this value and uses it as the default language for your channel.

  • Detection gives a default only. A language set in the dashboard or with !botlang always wins.
  • The bot reads the Twitch value each time it needs it. If you change the language on Twitch, the bot changes with it.
  • Channels with English as the stream language stay in English.

Set the Language

You can set the bot language in the dashboard or in chat. Only the broadcaster and moderators can change it.

Set the Language in the Dashboard

Open the Web Dashboard. Find the Bot Language card. Then select a language from the list.

  • Select Automatic to use the stream language from Twitch. This option is the default.
  • Select a language to hold the channel in that language. The Twitch stream language then has no effect.
  • The list has two groups. Written in advance holds the eight languages with translations ready. Translated when sent holds the other languages.
  • The dashboard saves your choice immediately. The bot changes language a few seconds later.

Set the Language in Chat

Chat accepts more languages than the dashboard list. Use these commands:

  • !botlang spanish - Sets the channel language to Spanish.
  • !botlang status - Shows the current language and where it came from.
  • !botlang off - Returns the channel to English.

Note: !botlang off and the English option both hold the channel in English. Automatic detection does not change it back.

To use automatic detection again, select Automatic in the dashboard.

Languages With Written Translations

Eight languages have translations that are written in advance: English, Spanish, French, German, Italian, Portuguese, Japanese, and Russian.

In these languages, fixed messages such as game announcements go to chat immediately. The words are the same each time.

The !botlang command accepts more languages than these eight. For a language without written translations, the bot translates each message as it sends it.

These messages are correct, but they are slower and the words can change between messages.

AI Replies

The bot writes AI replies new each time, so they are not limited to the eight languages.

The bot answers each person in the language that person used. If the language is not clear, the bot uses the language of your stream.

Time periods and language names follow the channel language. As an example, !followage writes its units in the channel language.

Dashboard Language

The dashboard has its own language setting. This setting is separate from the bot language.

The language picker is in the bottom corner of every dashboard page. The dashboard uses your browser language until you make a choice.

To see one page in a different language, add ?lang=ja to the end of the address.

Daily Check-In

Daily Check-In is a Channel Point Reward. Viewers check in once per stream to track their daily streak. The dashboard creates and manages the reward on Twitch.

Setup

  1. Open the WildcatSage Dashboard and go to the Daily Check-In section.
  2. Enable the toggle, then enter a reward title and Channel Point cost.
  3. Enter a response template with variables like $(user) and $(checkin_count), or enable AI Mode for unique replies.
  4. Select Save. The bot creates the reward on Twitch.

Available Variables

Available Variables
Variable What it does
$(user) Display name of the viewer who checked in
$(checkin_count) Total number of check-ins for the viewer
$(channel) Channel name
$(pronouns) Pronouns of the viewer who checked in
$(pronoun_subject) Subject pronoun of the viewer who checked in
$(pronoun_object) Object pronoun of the viewer who checked in
$(pronoun_possessive) Possessive pronoun of the viewer who checked in

Examples

Template: $(user) checked in! Day #$(checkin_count) 🎉

Output: WildcatGamer checked in! Day #14 🎉

AI Mode Prompt: Write a fun, short congratulatory message for $(user) on check-in number $(checkin_count).

Output: "WildcatGamer, 14 days straight? You're on fire! At this rate you'll outlast the sun. ☀️" — replies vary with each use.

Requirement: You must have Twitch Affiliate or Partner status to create Channel Point Rewards.
